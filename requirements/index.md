# 需求索引

共 109 条已发布需求：Gameplay 36 · Settlement 34 · Config 26 · UI 13

## Gameplay（36）

- **REQ-GAME-001** 呼叫转移依赖杠牌体系 — 呼叫转移与擦挂依赖刮风下雨杠牌体系（直杠/补杠/暗杠）。
- **REQ-GAME-002** 抢杠胡 — 补杠牌被胡触发抢杠胡×2，该次补杠不结算杠分，胡牌按点炮计。
- **REQ-GAME-003** 流局处理三步顺序固定 — 退税→查花猪→查大叫，顺序严格不可交换。
- **REQ-GAME-004** 海底炮胡法 — 摸最后一张打出被胡，加倍项海底炮×2。
- **REQ-GAME-005** 天胡胡法 — 庄家起手14张胡，32倍独立，不叠加番型或自摸加倍，赔付同自摸类。
- **REQ-GAME-006** 地胡胡法 — 闲家首摸即胡且全局无碰杠，32倍独立，赔付同自摸类，庄点可地胡可勾选。
- **REQ-GAME-007** 三层番型框架 — 基础番型（互斥取最高）/叠加番型（清一色）/叠加番型名（仅显示）三层判定。
- **REQ-GAME-008** 基础番型互斥取最高 — F01-F11互斥取最高（1~32倍），天胡地胡独立32倍不叠加。
- **REQ-GAME-009** 清一色叠加番型 — 手牌加副露全同花色触发清一色×4，可与所有基础番型叠加，无独立开关。
- **REQ-GAME-010** 叠加番型名仅显示 — S01-S09仅用于显示动画不产生倍数，倍数随创房下拉动态调整。
- **REQ-GAME-011** 金钩钓与碰碰胡互斥 — 两者结构互斥不可同时成立。
- **REQ-GAME-012** 将对与碰碰胡互斥 — 两者结构互斥。
- **REQ-GAME-013** 中张断幺九与全幺九互斥 — 逻辑互斥。
- **REQ-GAME-014** 门清与七对系可叠加 — 门清与七对系可叠加，暗杠仍算门清。
- **REQ-GAME-015** 根数计算规则 — 自带根全部参与触发（不扣除），实际根数=自带根+多余根。
- **REQ-GAME-016** 各番型自带根数 — 龙七对/清龙七对/将七对自带1根，十八罗汉/清十八罗汉自带4根。
- **REQ-GAME-017** 不可吃牌硬约束 — 行牌阶段不可吃牌，硬约束始终生效不受开关影响。
- **REQ-GAME-018** 摸牌操作 — 出牌阶段摸牌，手牌+1并可提牌。
- **REQ-GAME-019** 打牌操作 — 提牌后出牌，须不违反缺门，出牌后进入响应窗。
- **REQ-GAME-020** 碰牌操作 — 手牌≥2张同牌可碰，副露+1组并轮到自己出牌。
- **REQ-GAME-021** 直杠操作 — 手牌3张同牌可直杠，打牌者付2倍底分，补牌+1。
- **REQ-GAME-022** 补杠操作 — 已有碰且有第4张可补杠，向未胡玩家均摊收1倍底分，补牌+1。
- **REQ-GAME-023** 暗杠操作 — 手中4张同牌可暗杠，向未胡玩家均摊收2倍底分，补牌+1。
- **REQ-GAME-024** 补牌操作 — 杠后补牌，手牌+1。
- **REQ-GAME-025** 胡牌操作 — 牌型合法且缺门满足且限制层通过可胡，胡后退局进入结算。
- **REQ-GAME-026** 过操作 — 放弃此次响应，过手规则生效。
- **REQ-GAME-027** 操作优先级 — 胡牌（吃胡/自摸/抢杠胡）高于碰/杠。
- **REQ-GAME-028** 缺门花色不可碰杠 — 缺门花色不可碰、直杠、补杠、暗杠。
- **REQ-GAME-029** 补杠当回合限制 — 碰牌当回合不可补杠，须过手后。
- **REQ-GAME-030** 出牌与摸牌连贯 — A出牌与B摸牌同时开始，不等动画结束。
- **REQ-GAME-031** 后四张必胡 — 可勾选项（默认关），剩余≤4张必须胡，不显示【过】并强制海底捞月×2。
- **REQ-GAME-032** 必须打缺牌开关 — 默认开，三房生效，两房灰掉不可改。
- **REQ-GAME-033** 过手加番可胡开关 — 默认开，依赖过手胡，未选时灰掉。
- **REQ-GAME-034** 过手碰开关 — 默认开。
- **REQ-GAME-035** 庄点可地胡开关 — 默认开。
- **REQ-GAME-036** 死叫不算叫开关 — 默认关。

## Settlement（34）

- **REQ-SETTLEMENT-001** 呼叫转移机制 — 杠后补牌打牌点炮，A将杠分转交B（M8包赔），非一炮多响时触发。
- **REQ-SETTLEMENT-002** 呼叫转移一炮多响例外 — 杠上炮一炮多响不触发呼叫转移，杠分留A手中。
- **REQ-SETTLEMENT-003** 呼叫转移包含擦挂 — 呼叫转移时擦挂所得分数一并转交胡牌者。
- **REQ-SETTLEMENT-004** 擦挂机制 — A出牌致B直杠，B额外向其他未胡玩家各收1倍底分，不参与封顶。
- **REQ-SETTLEMENT-005** 杠分不参与封顶截断 — 杠分独立结算，不参与封顶，杠分转交仍非胡牌倍数。
- **REQ-SETTLEMENT-006** 流局退税不退呼叫转移已给杠分 — 退税退所有刮风下雨所得，但已转交的杠分不退。
- **REQ-SETTLEMENT-007** 杠上花杠分正常结算 — 杠分正常结算（A收直杠2倍），胡牌分按自摸。
- **REQ-SETTLEMENT-008** 退税触发对象为未听牌玩家 — 流局退税对象为未听牌玩家。
- **REQ-SETTLEMENT-009** 退税退回所有刮风下雨所得杠分 — 退税退回直杠/补杠/暗杠所得杠分。
- **REQ-SETTLEMENT-010** 退税不算倍数值不参与封顶 — 退税不作为倍数参与公式与封顶，仅退杠分。
- **REQ-SETTLEMENT-011** 查花猪触发条件 — 流局未胡且手牌仍有缺门花色者触发。
- **REQ-SETTLEMENT-012** 查花猪赔付对象为非花猪玩家 — 花猪玩家向非花猪玩家赔付。
- **REQ-SETTLEMENT-013** 查花猪赔付不参与封顶截断 — 赔付本身即封顶倍数，不再参与封顶截断。
- **REQ-SETTLEMENT-014** 已胡牌玩家不参与查花猪赔付 — 功夫设置下已胡玩家不参与赔付。
- **REQ-SETTLEMENT-015** 查大叫触发条件 — 流局未胡且未听牌（花猪除外）触发。
- **REQ-SETTLEMENT-016** 查大叫赔付对象为听牌玩家 — 未听牌（花猪除外）玩家向听牌玩家赔付。
- **REQ-SETTLEMENT-017** 查大叫赔付倍数按最大可能倍数 — 按听牌玩家最大可能番型倍数计，并参与封顶。
- **REQ-SETTLEMENT-018** 查大叫不计特定加倍项 — 不计绝张/抢杠胡/杠上花/杠上炮/海底捞月/海底炮。
- **REQ-SETTLEMENT-019** 胡牌类型不进倍数链 — 胡法只决定赔付方向，不进入倍数乘法链。
- **REQ-SETTLEMENT-020** 13种加倍项 — 自摸/杠上花/杠上炮/抢杠胡/清一色/门清/海底捞月/海底炮/夹心五/绝张/卡二条/中张断幺九/根。
- **REQ-SETTLEMENT-021** 自摸类赔付方向 — 自摸/杠上花/海底捞月/天胡/地胡向未胡玩家各收1倍（天胡地胡除外）。
- **REQ-SETTLEMENT-022** 点炮类赔付方向 — 点炮/抢杠胡/杠上炮/海底炮由放者单独付1倍，不含自摸。
- **REQ-SETTLEMENT-023** 天胡地胡不计自摸加倍 — 32倍独立番型，不再叠加自摸加倍。
- **REQ-SETTLEMENT-024** 自摸加底不参与封顶 — +1不参与封顶可超封顶且不显示；×2显示并参与封顶。
- **REQ-SETTLEMENT-025** 结算主公式计算 — 最终得分=底分×基础牌型倍数×可叠加牌型倍数×加倍项倍数。
- **REQ-SETTLEMENT-026** 封顶得分计算 — 封顶得分=底分×封顶倍数，作为上限。
- **REQ-SETTLEMENT-027** 实际得分取最小值 — 实际得分=min(最终得分,封顶得分)，超封顶则截断。
- **REQ-SETTLEMENT-028** 自摸加倍参与封顶截断 — 自摸×2显示在加倍项并参与封顶。
- **REQ-SETTLEMENT-029** 胡牌基础分参与封顶截断 — 倍数总和超封顶时截断（自摸加底+1除外）。
- **REQ-SETTLEMENT-030** 流水线第1步确定基础番型 — 12种互斥取最高，天胡/地胡独立。
- **REQ-SETTLEMENT-031** 流水线第3步累加加倍项根不扣除 — 累加13种加倍项，根自带全部参与不扣除。
- **REQ-SETTLEMENT-032** 流水线第4步应用封顶 — 底分×封顶倍数为上限，自摸加底可超封顶。
- **REQ-SETTLEMENT-033** 流水线第5步套用赔付方向 — 套用自摸/点炮/一炮多响/呼叫转移。
- **REQ-SETTLEMENT-034** 流水线第6步输出小结算 — 输出番型/流水/封顶标注。

## Config（26）

- **REQ-CONFIG-001** 点杠花配置 — 三选一（当点炮/当自摸多人/当自摸单人），B连杠自摸不算。
- **REQ-CONFIG-002** 呼叫转移开关配置 — 4人默认开，3人/2人灰掉不可改。
- **REQ-CONFIG-003** 擦挂开关配置 — 4人默认开，3人默认关可勾选，2人灰掉不可改。
- **REQ-CONFIG-004** 查大叫方式配置 — 当点炮/当自摸二选一，当自摸计自摸加倍。
- **REQ-CONFIG-005** 查大叫范围配置 — 全赔（含已胡）/不全赔（仅听牌且未胡）。
- **REQ-CONFIG-006** 一炮多响配置 — 开关（默认关），关闭按逆时针优先级，开启多人同胡各付1倍。
- **REQ-CONFIG-007** 自摸模式三选一 — 自摸加倍×2/自摸加底+1/自摸不加。
- **REQ-CONFIG-008** 创房13项番型开关 — 5基础+1特殊+7加倍项可独立开关，其余自动触发。
- **REQ-CONFIG-009** 底分配置取值 — 1/2/5，默认2。
- **REQ-CONFIG-010** 封顶倍数配置取值 — 4/8/16/32/64/256/512，默认32。
- **REQ-CONFIG-011** 及时雨补杠分计算 — 默认开，当回合补杠才计分，过手不计分仍计根。
- **REQ-CONFIG-012** 2倍起胡限制 — 默认关，倍数<2不可胡但仍可听牌不被查叫。
- **REQ-CONFIG-013** 速度配置 — 控制游戏节奏，不影响算分。
- **REQ-CONFIG-014** 人数配置 — 2人/3人/4人。
- **REQ-CONFIG-015** 局数配置 — 设定对局总局数。
- **REQ-CONFIG-016** 房数配置 — 三房/两房，决定牌张范围。
- **REQ-CONFIG-017** 换张配置 — 换3张。
- **REQ-CONFIG-018** 定庄配置 — 随机/房主。
- **REQ-CONFIG-019** 轮庄配置 — 赢家坐庄/逆时针/流局连庄。
- **REQ-CONFIG-020** 人数联动-默认房数 — 4人默认三房，3人/2人默认两房。
- **REQ-CONFIG-021** 人数联动-换牌方向 — 4人按骰子，3人随机顺/逆，2人恒对家。
- **REQ-CONFIG-022** 人数联动-座位 — 4人逆时针，3人房主下+上，2人房主对家。
- **REQ-CONFIG-023** 房数联动-定缺 — 三房有定缺，两房跳过。
- **REQ-CONFIG-024** 房数联动-花猪判定 — 三房正常，两房失效。
- **REQ-CONFIG-025** 房数联动-牌张 — 三房108张（万条筒），两房72张（条筒）。
- **REQ-CONFIG-026** 默认基准配置 — 4人8局三房108张换3张底分2封顶32自摸加倍赢家坐庄查大叫当点炮不全赔。

## UI（13）

- **REQ-UI-001** 点杠花系统显示名称 — 触发时显示胡法名称为自摸。
- **REQ-UI-002** 杠上花系统显示名称 — 显示胡法名称为杠上花。
- **REQ-UI-003** 自摸按钮显示 — 显示【自摸】+【过】，左侧显示牌和倍数。
- **REQ-UI-004** 点炮抢杠胡按钮显示 — 显示【胡】+【过】，上方显示倍数（不含自摸）。
- **REQ-UI-005** 封顶显示 — 达封顶显示「封顶」字样。
- **REQ-UI-006** 后四张必胡不显示过 — 后四张必胡不显示【过】。
- **REQ-UI-007** 托管超时默认胡 — 开启托管时超时默认胡。
- **REQ-UI-008** 碰杠胡按钮排序 — 【碰】→【杠】→【胡】/【自摸】→【过】。
- **REQ-UI-009** 听牌提示标签体系 — 箭头/多/大/优，优先级优>大>多>箭头。
- **REQ-UI-010** 可多杠状态按钮显示 — 可杠牌选择框+【杠】+【过】。
- **REQ-UI-011** 有自摸按钮时不可直接出牌 — 有自摸按钮时不可直接出牌。
- **REQ-UI-012** 显示胡牌番型开关 — 默认开，纯UI不影响算分。
- **REQ-UI-013** 暗杠不可见开关 — 默认关，纯UI不影响算分。
