# 功夫川麻

功夫川麻（又名血战川麻）是一种四川血战麻将的变体玩法。区别于普通麻将的核心特征包括：

- **定缺**：三房模式下玩家必须声明一门缺门花色，胡牌时不可含缺门花色。详见 [[缺门]]。
- **换三张**：开局交换 3 张同花色手牌，方向由骰子决定。详见 [[换三张]]。
- **刮风下雨**：川麻特有的杠牌统称体系。详见 [[刮风下雨]]。
- **呼叫转移与擦挂**：杠上炮时的分数转交与额外收取机制。详见 [[呼叫转移与擦挂]]。
- **血战到底**：一家胡牌后游戏不结束，其余玩家继续，直至剩一人未胡或流局。
- **过手规则**：可胡不胡/可碰不碰后的约束。详见 [[过手规则]]。
- **掷骰双分流**：同一组骰子同时决定摸牌起点与换牌方向。详见 [[掷骰双分流]]。
- **流局处理**：流局时退税→查花猪→查大叫的固定处理顺序。详见 [[流局处理]]。
- **结算流水线**：胡牌后 6 步结算框架。详见 [[结算流水线]]。

## 基本参数

| 维度 | 内容 |
|---|---|
| 牌数 | 三房 108 张（默认）/ 两房 72 张（可选） |
| 花色 | 万 1-9、条 1-9、筒 1-9 × 4（两房去掉万子） |
| 起手 | 庄家 14 张，闲家 13 张 |
| 胡牌张数 | 14 张 |
| 将牌 | 数牌 2 / 5 / 8 |
| 人数 | 2-4 人 |

## 基础术语

- **将牌**：数字 2/5/8 的牌，胡牌所需。详见 [[将牌与根]]。
- **根**：4 张相同的牌（手牌 + 碰杠区合计），每根 ×2 倍。详见 [[将牌与根]]。
- **听牌**：差一张可胡的状态。
- **流局**：牌墙摸完且无人胡。

## 配置体系

游戏支持房间级配置，包括：三房/两房选择、定庄模式（随机/房主）、轮庄模式（赢家坐庄/逆时针/流局连庄）、换张数量（3张/4张/不换）、定缺必须打缺牌、过手胡/过手加番可胡、点杠花收分模式等。详见源文档 [[基础规则]] 及配置篇。

## 游戏流程

完整时序：开局准备 → 定庄 → 掷骰 → 发牌 → 换三张 → 定缺 → 行牌 → 结束判定 → 流局处理/正常结算 → 轮庄续局。

- 行牌阶段操作优先级：胡（吃胡/自摸/抢杠胡）> 碰/杠
- 血战到底：一人胡牌后不结束，剩余玩家继续，直至仅剩 1 人未胡或牌墙摸完
- 流局处理顺序固定：退税 → 查花猪 → 查大叫
- 结算流水线：6 步（基础番型 → 叠加牌型 → 加倍项 → 封顶 → 赔付方向 → 小结算）
- 续局：创房设置 8/12/16/24 局，最后一局后进入大结算

详见源文档 [[游戏流程]]。

### 番型与结算

- 三层番型体系：基础番型（11种互斥取高）→ 叠加番型（清一色可叠）→ 叠加番型名（9种仅显示）。详见 [[番型体系]]。
- 两层胡牌判定：番型合法性 → 胡牌类型合法性（限制层+胡牌方式）。详见 [[胡牌判定]]。
- 结算公式：底分×基础牌型×叠加牌型×加倍项，封顶截断。详见 [[结算公式]]。
- 9种胡法：自摸类3（自摸/杠上花/海底捞月）+ 点炮类4（点炮/抢杠胡/杠上炮/海底炮）+ 特殊类2（天胡/地胡32倍独立）。
- 13种加倍项、杠分独立结算、自摸加倍vs自摸加底。

### 创房配置

15项面板配置 + 13项规则开关 + 13项番型开关。配置对结算影响分3级：直接影响10项/间接影响6项/不影响8项。详见 [[创房配置]]。
