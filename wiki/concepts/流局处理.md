# 流局处理

流局处理是 [[功夫川麻]] 中牌墙摸完且无人胡牌（或剩余未胡玩家均无法胡）时的固定处理流程。

## 处理顺序（严格有序，不可交换）

```
流局
  ├─ 1. 退税
  ├─ 2. 查花猪
  └─ 3. 查大叫
```

## 1. 退税

| 项 | 规则 |
|---|---|
| 触发对象 | 未听牌的玩家 |
| 退回内容 | 所有 [[刮风下雨]]（直杠 + 补杠 + 暗杠）所得分数 |
| 不退回 | [[呼叫转移与擦挂]] 中已给出去的杠分 |

> 退税是流局处理的第一步，在查花猪和查大叫之前执行。

## 2. 查花猪

| 项 | 规则 |
|---|---|
| 触发条件 | 流局时未胡且手牌仍有 [[缺门]] 花色的牌 |
| 赔付 | 赔非花猪玩家封顶倍数（取创房选中的 4/8/16/32 之一） |
| 特例 | 功夫设置：已胡牌不赔 |

## 3. 查大叫

| 项 | 规则 |
|---|---|
| 触发条件 | 流局时未胡且未听牌（花猪除外）的玩家 |
| 赔付对象 | 听牌玩家 |
| 赔付倍数 | 最大可能倍数 |
| 配置 | 当点炮 / 当自摸 |
| 配置 | 全赔（含已胡）/ 不全赔（仅听牌且未胡） |

## 关联

- 源自 [[游戏流程]] §九、[[基础规则]] §二.1、[[结算]] §八
- 查花猪赔付=封顶倍数本身（不参与封顶截断，见 [[结算公式]]）
- 查大叫不计：绝张/抢杠胡/杠上花/杠上炮/海底捞月/海底炮
- 查大叫配置（当点炮/当自摸、全赔/不全赔）见 [[创房配置]] §六.3-六.4
- 退税依赖 [[刮风下雨]] 的杠分体系
- 查花猪依赖 [[缺门]] 的花色约束
- 与 [[结算流水线]] 共同构成 [[功夫川麻]] 的结算体系
