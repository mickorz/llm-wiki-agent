# 结算公式

结算公式是 [[功夫川麻]] 胡牌后计算最终得分的数学公式与封顶规则。

## 主公式

```
最终得分 = 底分 × 基础牌型倍数 × 可叠加牌型倍数 × 加倍项倍数
封顶得分 = 底分 × 封顶倍数
实际得分 = min(最终得分, 封顶得分)
           （自摸加底的一底不参与封顶截断）
```

## 各项来源

| 项 | 来源 | 说明 |
|---|---|---|
| 底分 | [[创房配置]] | 1/2/5（默认2） |
| 基础牌型倍数 | [[番型体系]] | 11种互斥取最高（1~32倍） |
| 可叠加牌型倍数 | [[番型体系]] | F12清一色×4 |
| 加倍项倍数 | [[番型体系]] 13种 | 自摸/杠上花/杠上炮/抢杠胡/门清/海底捞月/海底炮/夹心五/绝张/卡二条/中张/根 |
| 封顶倍数 | [[创房配置]] | 4/8/16/32/64/256/512（默认32） |

## 自摸模式（创房三选一）

| 模式 | 倍数 | 显示在加倍项 | 可超封顶 |
|---|---|---|---|
| 自摸加倍（默认） | ×2 | 是 | 否（参与封顶截断） |
| 自摸加底 | +1 | 否（不显示） | 是（不参与截断） |
| 自摸不加 | 不变 | — | — |

> 天胡/地胡不计自摸加倍（独立32倍）。

## 封顶作用域

| 结算项 | 参与封顶截断 | 说明 |
|---|---|---|
| 胡牌基础分 | 参与 | 倍数总和>封顶→截断；自摸加底+1不参与 |
| 杠分（直杠/补杠/暗杠） | 不参与 | 独立结算，不进入封顶 |
| 查花猪赔付 | 不参与 | 赔的就是封顶倍数本身 |
| 查大叫赔付 | 参与 | 按手牌最大番型倍数算 |
| 退税 | 不算倍数 | 退回杠分 |
| 呼叫转移杠分 | 不参与 | 杠分转交，仍非胡牌倍数 |
| 擦挂 | 不参与 | 收1倍底分固定 |

## 赔付方向

| 类别 | 胡法 | 赔付 |
|---|---|---|
| 自摸类 | 自摸/杠上花/海底捞月/天胡/地胡 | 胡家收所有未胡玩家各1倍 |
| 点炮类 | 点炮/抢杠胡/杠上炮/海底炮 | 点炮/放杠者单独付1倍 |
| 一炮多响 | 多人同时胡 | 点炮玩家按人数各付1倍 |
| 呼叫转移 | 杠上炮（非一炮多响） | 杠分转交胡牌者 |

## 结算举例

```
玩家A: 111万+234万+567万+89万+999万 → 摸1万自摸
基础: 一条龙(4倍) × 清一色(4倍) = 清龙(16倍)
加倍: 1根(×2) + 自摸(×2) + 海底捞月(×2) + 门清(×2)
最终: 5 × 16 × 2 × 2 × 2 × 2 = 1280
封顶: 5 × 32 = 160
实际: min(1280, 160) = 160
赔付: A+480, B/C/D各-160
```
