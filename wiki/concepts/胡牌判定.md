# 胡牌判定

胡牌判定是 [[功夫川麻]] 的两层判定体系：第一层番型合法性，第二层胡牌类型合法性。两层都通过方可胡牌。

## 两层判定流程

```
手牌14张 + 待胡的牌
  │
  ▼
第一层 · 番型合法性（[[番型体系]]）
  ├─ 缺门是否满足？（含缺门 → 不可胡）
  ├─ 是否符合基础番型之一？
  └─ 是否触发互斥？（取倍数最高）
  │ ✅ 通过
  ▼
第二层 · 胡牌类型合法性
  ├─ 限制层检查（缺门/2倍起胡/后四张必胡/过手胡/死叫不算叫）
  └─ 胡牌方式判定（自摸类/点炮类/特殊类）
  │ ✅ 通过
  ▼
  可胡
```

## 共用限制层

| 限制 | 规则 | 默认 |
|---|---|---|
| [[缺门]] | 三房时手牌+副露不可含缺门花色 | 硬约束 |
| 2倍起胡 | 胡牌倍数<2不可胡，但仍可听牌不被查叫 | 默认关 |
| 后四张必胡 | 剩余≤4张强制胡，不显示【过】 | 默认关 |
| [[过手规则]] | 可胡不胡后未过手前不可胡所有可胡牌 | 默认开 |
| 死叫不算叫 | 听口全在牌河/副露则不算听牌 | 默认关 |

## 9种独立胡法

### 自摸类（3种）— 收所有未胡玩家各1倍（含自摸加倍）

| 胡法 | 触发 | 加倍项 |
|---|---|---|
| 自摸 | 摸到一张牌胡牌 | 自摸项×2/加底+1/不加 |
| 杠上花（=杠上开花=杠开） | 自己开杠后补牌胡牌 | 自摸×2 + 杠上花×2 |
| 海底捞月 | 摸到最后一张牌自摸 | 自摸×2 + 海底捞月×2 |

### 点炮类（4种）— 点炮/放杠者单独付1倍（不含自摸项）

| 胡法 | 触发 | 加倍项 |
|---|---|---|
| 点炮 | 别人打出的牌被胡 | 不含自摸项 |
| 抢杠胡 | 补杠的牌被胡；该次补杠不结算杠分 | 抢杠胡×2 |
| 杠上炮 | 杠后打出被胡；触发[[呼叫转移与擦挂]] | 杠上炮×2 |
| 海底炮 | 摸最后一张打出被胡 | 海底炮×2 |

### 特殊类（2种）— 32倍独立，赔付方向同自摸类

| 胡法 | 触发 | 特点 |
|---|---|---|
| 天胡 | 庄家起手14张直接胡 | 不叠加任何番型/自摸项 |
| 地胡 | 闲家首摸即胡且全局无碰/杠 | 同上；庄点可地胡可创房勾选 |

## 核心原则

**胡牌类型不进入倍数乘法链，只决定赔付方向（钱从谁流向谁）。**

```
最终得分 = 底分 × 基础牌型倍数 × 可叠加牌型倍数 × 加倍项倍数
```

倍数链与胡牌类型无关——无论自摸还是点炮，倍数链计算方式完全相同。

## 非胡法配置项

| 配置 | 说明 |
|---|---|
| 点杠花 | A出牌→B直杠→B补牌自摸；创房3选1（当点炮/当自摸多人默认/当自摸单人）；连杠后自摸不算 |
| 一炮多响 | 创房开关（v1默认关）；关闭=逆时针顺序优先级；开启=多人同时胡各付1倍；一炮多响时呼叫转移不触发 |

## 胡牌合法性 checklist

1. 缺门满足？ 2. 番型合法？ 3. 互斥取高？ 4. 天胡/地胡独立？ 5. 2倍起胡满足？ 6. 后四张必胡？ 7. 过手胡未触发？ 8. 死叫不算叫？ 9. 一炮多响规则？ 10. 胡牌方式归类正确？ 11. 呼叫转移？ 12. 抢杠胡杠分无效？
