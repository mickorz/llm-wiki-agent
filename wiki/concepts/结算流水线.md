# 结算流水线

结算流水线是 [[功夫川麻]] 中胡牌后的 6 步结算框架。

## 6 步流程

```
胡牌玩家
  ├─ 1. 确定基础番型（12 种互斥取最高倍数；天胡/地胡独立）
  ├─ 2. 套用叠加牌型（9 种特殊名称）—— 名称优先
  ├─ 3. 累加加倍项（13 种；自带根全部参与触发（不扣除））
  ├─ 4. 应用封顶：底分 × 封顶倍数
  │      · 自摸加底特例：自摸加的一底可超过封顶倍数
  ├─ 5. 套用赔付方向
  │      · 自摸：胡牌玩家收取所有未胡玩家各一倍
  │      · 点炮：点炮玩家向胡牌玩家支付一倍
  │      · 一炮多响：点炮玩家按胡牌人数各付一倍
  │      · 呼叫转移：杠上炮时杠分转交胡牌者（一炮多响时不触发）
  └─ 6. 输出小结算（番型 / 流水 / 封顶标注）
```

## 关键规则

- **基础番型互斥**：12 种中取最高倍数，不叠加
- **叠加牌型**：9 种特殊名称，名称优先（叠加于基础番型之上）
- **加倍项**：13 种，[[将牌与根]] 中的「根」自带全部参与触发（不扣除）
- **封顶**：底分 × 封顶倍数为上限；自摸加底特例可超过封顶
- **赔付方向**：取决于胡牌方式（自摸/点炮/一炮多响/呼叫转移）
