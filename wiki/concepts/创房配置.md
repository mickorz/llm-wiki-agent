# 创房配置

创房配置是 [[功夫川麻]] 好友房创房面板的完整配置体系，包含15项面板配置 + 13项规则开关 + 13项番型开关。

## 配置分类

| 分类 | 数量 | 内容 |
|---|---|---|
| 基本配置 | 7项 | 速度/人数/局数/底分/封顶/房数/换张 |
| 规则 | 13项开关 | 必须打缺牌/及时雨/过手胡/过手加番可胡/过手碰/擦挂/呼叫转移/后四张必胡/庄点可地胡/死叫不算叫/2倍起胡/显示胡牌番型/暗杠不可见 |
| 计分 | 4项 | 自摸/点杠花/查大叫方式/查大叫范围 |
| 番型 | 13项开关+倍数下拉 | 天地胡/海底捞月/海底炮/断幺九/全幺九/将对/门清/夹心五/绝张/卡二条/对对胡/将七对/一条龙 |
| 定庄/轮庄 | 2项 | 定庄(随机/房主)+轮庄(赢家坐庄/逆时针/流局连庄) |

## 默认基准配置（验收口径）

4人 · 8局 · 三房108张 · 换3张 · 底分2 · 封顶32倍 · 自摸加倍 · 赢家坐庄 · 查大叫(当点炮/不全赔)

## 对结算影响分类

### 直接影响算分（10项）

底分、封顶、自摸模式、点杠花、查大叫方式、查大叫范围、呼叫转移、擦挂、及时雨、后四张必胡、庄点可地胡、番型13项

### 间接影响算分（6项）

必须打缺牌、过手胡、过手加番可胡、过手碰、死叫不算叫、2倍起胡

### 不影响算分（8项）

速度、局数、人数、房数、换张、显示胡牌番型、定庄、轮庄

## 人数联动

| 受影响项 | 4人 | 3人 | 2人 |
|---|---|---|---|
| 默认房数 | 三房 | 两房(自动) | 两房(自动) |
| 呼叫转移 | 开(可关) | 灰掉不可改 | 灰掉不可改 |
| 擦挂 | 开(可关) | 关(可开) | 灰掉不可改 |
| 换牌方向 | 按骰子 | 对家点数随机顺/逆 | 恒对家 |
| 座位 | 逆时针入房 | 房主下+上 | 房主对家 |

## 房数联动

| 受影响项 | 三房 | 两房 |
|---|---|---|
| 牌张 | 108张(万条筒) | 72张(条筒) |
| 定缺 | 有 | 无(跳过) |
| 必须打缺牌 | 生效 | 灰掉 |
| 花猪判定 | 正常 | 失效 |

## 13项规则开关默认值

| 规则 | 默认 | 依赖 |
|---|---|---|
| 必须打缺牌 | 开 | 三房生效，两房灰掉 |
| 及时雨 | 开 | 补杠须当回合执行才计分 |
| 过手胡 | 开 | — |
| 过手加番可胡 | 开 | 依赖过手胡（未选时灰掉） |
| 过手碰 | 开 | — |
| 擦挂 | 开(4人) | 2人灰掉 |
| 呼叫转移 | 开(4人) | 3/2人灰掉 |
| 后四张必胡 | 关 | — |
| 庄点可地胡 | 开 | — |
| 死叫不算叫 | 关 | — |
| 2倍起胡 | 关 | — |
| 显示胡牌番型 | 开 | 纯UI |
| 暗杠不可见 | 关 | 纯UI |
