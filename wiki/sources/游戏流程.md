## Summary

本文按完整时序串联功夫川麻一局游戏的全流程：定庄 → 掷骰 → 发牌 → 换三张 → 定缺 → 行牌 → 胡/流局 → 退税 → 查花猪 → 查大叫 → 结算 → 轮庄。文档包含全流程 ASCII 图、各阶段详细规则表、操作优先级、结束判定条件、流局处理顺序（固定为退税→查花猪→查大叫）、结算流水线（6 步）以及续局/大结算规则。

## Key Claims

- **全流程时序**：开局准备 → 定庄 → 掷骰 → 发牌 → 换三张 → 定缺 → 行牌 → 结束判定 → 流局处理/正常结算 → 轮庄续局。
- **骰子双分流**：同一组骰子结果同时决定两件独立的事——摸牌起点（4 档：5/9 自家、2/6/10 下家、3/7/11 对家、4/8/12 上家）和换牌方向（3 档：对家/上家/下家）。详见 [[掷骰双分流]]。
- **发牌节奏**：庄家 14 张（4+4+4+1+1），闲家 13 张（4+4+4+1），逆时针正序发牌。
- **换牌提示逻辑**：服务端按花色得分算法推荐换牌花色——花色张数≥N 每张×4000 分，<N 每张×10000000 分，再叠加杠子/刻子/对/顺/搭/门子/孤张得分，花色得分最小者推荐。
- **血战到底**：一人胡牌后游戏不结束，剩余玩家继续行牌，直至仅剩 1 人未胡或牌墙摸完。
- **操作优先级**：胡（吃胡/自摸/抢杠胡）> 碰/杠。不可一炮多响时按打出者逆时针顺序，允许时可多人同时胡。
- **流局处理顺序固定**：退税 → 查花猪 → 查大叫（严格有序，不可交换）。详见 [[流局处理]]。
- **结算流水线**：6 步——确定基础番型 → 套用叠加牌型 → 累加加倍项 → 应用封顶 → 套用赔付方向 → 输出小结算。详见 [[结算流水线]]。
- **轮庄**：赢家坐庄（默认）/ 逆时针轮庄 / 流局连庄（可叠加）；流局时按流局连庄子项处理。
- **续局**：创房设置 8/12/16/24 局；最后一局后进入大结算（复用边锋干瞪眼模板）。
