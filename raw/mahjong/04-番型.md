## 零、番型总览（三层关系图）

> 本章番型分三层：**基础番型（互斥取高）→ 叠加番型（可叠加）→ 叠加番型名（仅显示用）**。以下为统一参考图，后续各章节均以此为基准。

| 层级 | 编号 | 内容 | 关系 |
|---|---|---|---|
| **① 基础番型** | F01~F11（11 项）| 3N+2（7）+ 2N（2）+ 特殊（2）| **互斥取最高**；天胡/地胡独立 32 倍不叠加 |
| **② 叠加番型** | F12 清一色（1 项） | 胡牌手牌全同花色 → ×4 | **可叠加**到基础番型（与全幺九/金钩钓/龙七对/平胡等叠加）；S08 十八罗汉不含清一色成分 |
| **③ 叠加番型名** | S01~S09（9 个） | 清碰/清龙/清七对/龙七对/清龙七对/清幺九/清金钩钓/十八罗汉/清十八罗汉 | **仅显示/动画用**；倍数按基础×叠加×加倍项计算，实际值以 [结算](06-结算.md) §1.1 为准 |

> **关键区分**：基础番型之间互斥 → 叠加番型可叠 → 叠加名仅组合显示。F12 清一色是唯一独立叠加番型，与 S01~S07/S09 共用清一色成分。

## 一、三大类总览

### 1.1 结构分类

| 结构类 | 数学形式 | 牌型构成 | 代表番型 | 出处 |
|---|---|---|---|---|
| **3N+2** | 4 副 + 1 对 = 14 | 4 组面子（顺 / 刻 / 杠）+ 1 对将牌 | 平胡、对对胡、全幺九、一条龙、金钩钓、将对、将金钩钓 | 2.3.3.0 |
| **2N** | 7 对子 = 14 | 7 个对子，无顺子/刻子面子 | 七对、将七对 | 2.3.3.0 |
| **特殊** | 独立判定 | 不与 3N+2 / 2N 叠加取高 | 天胡、地胡 | 2.3.3.0 |

> **番**与**倍数**的换算关系：`倍数 = 2^番数`（仅做语义参考，不严格约束可配置番型；F11 全幺九可配 4/8 倍、F02 对对胡可配 2/4 倍，均以创房实际下拉值为准）。本表统一以**倍数**参与结算。

### 1.2 判定流水线

```
14 张手牌 + 缺门验证
  │
  ├─ 缺门未满足 → 任何番型均不可胡
  │
  ├─ 特殊结构（天胡 / 地胡）
  │    ├─ 天胡：庄家起手 14 张直接胡牌
  │    └─ 地胡：闲家第一次摸牌就胡，且全局无碰 / 杠
  │         → 命中：独立判定，32 倍，不与其他叠加
  │
  ├─ 2N（七对结构）
  │    ├─ 七对 → 4 倍
  │    ├─ 将七对（由 2/5/8 组成的七对）→ 16 倍（与七对互斥）
  │    └─ 龙七对（1 根 + 七对）作为叠加番型处理（§六）
  │
  ├─ 3N+2（4 副 + 1 对）
  │    ├─ 平胡 → 1 倍
  │    ├─ 对对胡（4 副刻子/杠 + 1 对）→ 2 / 4 倍（可配置）
  │    ├─ 全幺九（每组含 1 或 9）→ 4 倍（默认）/ 8 倍（创房可下拉）
  │    ├─ 一条龙（同花色 123 / 456 / 789 三组顺子）→ 4 倍
  │    ├─ 金钩钓（4 副全在副露 + 手牌 1 张单吊）→ 4 倍（与碰碰胡互斥）
  │    ├─ 将对（全由 2/5/8 组成的碰碰胡）→ 8 倍（与碰碰胡互斥）
  │    └─ 将金钩钓（由 2/5/8 组成的金钩钓）→ 16 倍（与将对、金钩钓互斥）
  │
  ├─ 🆕 清一色（叠加番型）
  │    └─ 手牌 + 副露全同花色 → ×4（叠加到基础番型，可与全幺九/金钩钓/龙七对/平胡叠加）
  │
  └─ 多种基础番型同时满足 → 取倍数最高一种
       → 应用叠加番型（特殊名称）+ 加倍项 → 详见 [结算](06-结算.md)
```

> 出处：2.3.3.0、2.3.3.1、2.3.3 顶部。

### 1.3 全局互斥原则

| 原则 | 说明 | 出处 |
|---|---|---|
| **基础番型互斥** | 同结构 / 跨结构满足时**只取倍数最高一种**，不会叠加 | 2.3.3 顶部 |
| **天胡 / 地胡独立** | 命中天胡 / 地胡时**不与任何番型叠加**，即使其他番型倍数更高 | 2.3.3.1 #10 / #11 |
| **结构内升级** | 同结构内取倍数最高的番型 | 2.4.1 |
| **跨结构互斥** | 七对与平胡不可同时计；七对满足且倍数更高则取七对 | 2.3.3.1 #4-#5 |
| **金钩钓 / 碰碰胡互斥** | 金钩钓与碰碰胡结构互斥（金钩钓手牌只有 1 张单吊） | 2.3.3.1 #7 |
| **将对 / 碰碰胡互斥** | 将对是「由 2/5/8 组成的碰碰胡」，与「普通碰碰胡」互斥 | 2.3.3.1 #8 |
| **将金钩钓 / 将对 / 金钩钓互斥** | 三者互斥 | 2.3.3.1 #9 |
| **叠加番型可叠** | 门清、中张（断幺九）、清一色、根、自摸 等可在基础番型确定后**叠加**；与七对 / 将七对 / 龙七对 / 清七对 / 清龙七对 / 全幺九 / 金钩钓 **可叠**；与平胡**可叠**（平胡本身=1 倍，叠加后 1 × 任何倍数 = 任何倍数，不改变结果，标注以澄清）（产品原话）| 2.3.3.3 |

| ID | 番型 | 番数 | 倍数 | 结构类 | 备注 | 出处 |
|---|---|---|---|---|---|---|
| F01 | 平胡 | 0番 | **1 倍** | 3N+2 | 4 副顺/刻/杠 + 1 对 | 2.3.3.1 #1 |
| F02 | 对对胡（碰碰胡） | 1番 | **2 / 4 倍**（可配置） | 3N+2 | 4 副全刻/杠 + 1 对 | 2.3.3.1 #2 |
| F03 | 七对 | 2番 | **4 倍** | 2N | 7 对子 | 2.3.3.1 #4 |
| F04 | 将七对 | 4番 | **16 倍** | 2N | 由 2/5/8 组成的七对；与七对互斥 | 2.3.3.1 #5 |
| F05 | 一条龙 | 2番 | **4 倍** | 3N+2 | 同花色 123/456/789 三组顺 | 2.3.3.1 #6 |

| F07 | 将对 | 3番 | **8 倍** | 3N+2 | 全由 2/5/8 组成的碰碰胡；与碰碰胡互斥 | 2.3.3.1 #8 |

| F09 | 天胡 | 5番 | **32 倍** | 特殊 | 庄起手 14 张直接胡；不与其他叠加 | 2.3.3.1 #10 |
| F10 | 地胡 | 5番 | **32 倍** | 特殊 | 闲家首摸就胡且全局无碰/杠；不与其他叠加 | 2.3.3.1 #11 |
| F11 | **全幺九** | 2番 | **×4（默认）/ ×8（创房可下拉）** | 3N+2 | 每副 + 对子至少含 1 张 1 或 9 序数牌 | 2.3.3.1 #3 |

## 二、3N+2 类（4 副 + 1 对）

> **结构公式**：`14 = 4 副 × 3 + 1 对 × 2`  
> **1 副** = 顺子或刻子（或杠）；**1 对** = 将牌。  
> 门前副露（碰、杠）计入 4 副；缺门花色不可胡。

### 2.1 平胡（F01）

#### 2.1.1 判定条件

| 判定项 | ✅ 满足 | ❌ 不满足 → 改判 |
|---|---|---|
| **3N+2 结构** | 14 张可拆为 4 副 + 1 对 | 改判 七对 / 天胡 / 地胡 |
| **非全刻** | 4 副不全为刻/杠（至少 1 副顺） | 改判 对对胡 |
| **非全同花色** | 含 2 种及以上序数花色 | 改判 清一色变体（清碰 / 清龙 / 清幺九 / 清金钩钓） |
| **非特殊番型** | 非 2N / 特殊 | 改判对应番型 |

#### 2.1.2 行牌依赖

| 行牌状态 | 能否计平胡 | 说明 |
|---|---|---|
| **有碰 / 杠** | ✅ | 平胡不要求门清 |
| **含缺门** | ❌ | 不可胡（缺一门才能胡） |

#### 2.1.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 平胡 ← 升级 | **对对胡** | 取对 |
| 平胡 ← 升级 | **清碰**（清一色 + 对对胡） | 取清碰 |
| 平胡 ← 升级 | **清龙**（清一色 + 一条龙） | 取清龙 |
| 平胡 ← 升级 | **清幺九**（清一色 + 全幺九） | 取清幺九 |
| 平胡 ← 升级 | **清金钩钓**（清一色 + 金钩钓） | 取清金钩钓 |
| 🆕 可叠加 | **门清**（叠加项）| 可叠加（平胡 × 门清 = 1 × 2 = 2 倍）|
| 🆕 可叠加 | **中张 / 断幺九**（叠加项）| 可叠加（平胡 × 中张 = 1 × 2 = 2 倍）|
| 🆕 可叠加 | **清一色**（叠加项）| 可叠加（平胡 × 清一色 = 1 × 4 = 4 倍）|
| 🆕 互斥 | **全幺九**（F11）| 不可同时计（全幺九要求每副含 1/9，平胡无此要求，两者 3N+2 拆解结果互斥——同一手牌不可能同时满足"每副含1/9"和"至少一不含1/9"）|
| 互斥 | **七对**（2N） | 取倍数高者 |
| 互斥 | **天胡 / 地胡** | 取天地胡（不叠加） |

#### 2.1.4 判定流程

```
14 张能拆 3N+2 + 缺门满足?
  ├─ 否 → 七对 / 天胡 / 地胡
  └─ 是 → 4 副全刻 + 1 对、无顺?
        ├─ 是 → 对对胡 / 将对（视牌点）
        └─ 否 → 全同花色?
              ├─ 是 → 清一色变体（§五）
              └─ 否 → ✅ 平胡
```

#### 2.1.5 正反示例

| 类型 | 手牌 | 说明 |
|---|---|---|
| **✅ 正** | 123 万 + 456 万 + 789 万 + 123 筒 + 11 筒 | 三色，4 副 + 1 对，含顺子，无全同花色，无全刻 |
| **❌ 反 → 对对胡** | 111 万 + 222 万 + 333 万 + 444 万 + 99 筒 | 全刻，无顺 |
| **❌ 反 → 一条龙** | 123 筒 + 456 筒 + 789 筒 + 234 条 + 88 条 | 含一条龙，取一条龙 |
| **❌ 反 → 全幺九** | 123 万 + 456 万 + 789 万 + 111 条 + 99 条 | 每副均含 1/9，取全幺九 |
| **❌ 反 → 七对** | 11 万 + 22 万 + 33 万 + 44 万 + 55 万 + 66 万 + 77 万 | 7 对子结构，取七对 |

### 2.2 对对胡 / 碰碰胡（F02）

#### 2.2.1 判定条件

| 判定项 | ✅ 满足 | ❌ 不满足 → 改判 |
|---|---|---|
| **3N+2 结构** | 14 张 = 4 副 + 1 对 | 七对 / 天胡 / 地胡 |
| **全刻形** | 4 副均为刻子 / 杠，无顺子 | 平胡 |
| **非全 2/5/8** | 不是将将碰碰胡 | 将对 |

#### 2.2.2 行牌依赖

| 行牌状态 | 能否计对对胡 | 说明 |
|---|---|---|
| **含缺门** | ❌ | 不可胡 |
| **可配置倍数** | 2 / 4 倍 | 创房规则可下拉 |

#### 2.2.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 对对胡 → 升级 | **将对**（全 2/5/8） | 取将对 |
| 对对胡 → 升级 | **清碰**（清一色 + 对对胡） | 取清碰 |
| 🆕 可叠加 | **门清**（叠加项）| 可叠加（对对胡 × 门清 = 2 × 2 = 4 倍）|
| 🆕 可叠加 | **中张 / 断幺九**（叠加项）| 可叠加（对对胡 × 中张 = 2 × 2 = 4 倍）|
| 🆕 可叠加 | **清一色**（叠加项）| 可叠加（清碰 = 对对胡 × 清一色 = 8 倍）|
| 🆕 互斥 | **将对**（F07）| 不可同时计（将对是「全 2/5/8 的碰碰胡」，对对胡是「普通碰碰胡」，结构互斥）|
| 互斥 | **金钩钓** | 取倍数高者 |
| 互斥 | **七对** | 取倍数高者 |

#### 2.2.4 判定流程

```
14 张能拆 3N+2 + 全刻 + 缺门满足?
  ├─ 否 → 平胡 / 七对 / 天胡 / 地胡
  └─ 是 → 全 2/5/8?
        ├─ 是 → 将对
        └─ 否 → 全同花色?
              ├─ 是 → 清碰（清一色 + 对对胡）
              └─ 否 → ✅ 对对胡
```

#### 2.2.5 正反示例

| 类型 | 手牌 | 说明 |
|---|---|---|
| **✅ 正** | 111 万 + 222 万 + 333 条 + 444 条 + 99 筒 | 4 副全刻 + 1 对 |
| **❌ 反 → 平胡** | 123 万 + 456 万 + 789 万 + 111 条 + 99 筒 | 含顺子 |
| **❌ 反 → 将对** | 222 万 + 555 万 + 888 万 + 222 条 + 55 筒 | 全 2/5/8，取将对 |

### 2.3 全幺九（F11）

#### 2.3.1 判定条件

| 判定项 | ✅ 满足 | ❌ 不满足 → 改判 |
|---|---|---|
| **3N+2 结构** | 14 张 = 4 副 + 1 对 | 七对 / 天胡 / 地胡 |
| **每副含 1/9** | **每一副**刻/顺/杠 + 对子都包含 1 或 9 序数牌 | 平胡 / 其他 |
| **非全同花色** | — | 清幺九（清一色 + 全幺九） |

> 注意：**不是要求全部牌都是 1/9**，而是每副（含将牌）**至少有一张**是 1 或 9。

#### 2.3.2 行牌依赖

| 行牌状态 | 能否计全幺九 | 说明 |
|---|---|---|
| **含缺门** | ❌ | 不可胡 |

#### 2.3.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 全幺九 → 升级 | **清幺九**（清一色 + 全幺九） | 取清幺九 |
| 互斥 | **断幺九 / 中张**（加倍项） | 不可同时计（全幺九 vs 断幺九逻辑互斥）|
| 🆕 可叠加 | **门清**（叠加项）| 可叠加（全幺九 × 门清 = 4 × 2 = 8 倍；×8 时 = 16 倍）|
| 🆕 可叠加 | **清一色**（叠加项）| 可叠加（清幺九 = 全幺九 × 清一色 = 4 × 4 = 16 倍（默认）；若创房全幺九调为 ×8，则清幺九 = 8 × 4 = 32 倍，参见 [07-配置 §八](07-配置.md)）|
| 互斥 | **七对** | 取倍数高者 |

#### 2.3.4 判定流程

```
14 张能拆 3N+2 + 每副含 1/9 + 缺门满足?
  ├─ 否 → 平胡 / 其他番型
  └─ 是 → 全同花色?
        ├─ 是 → 清幺九
        └─ 否 → ✅ 全幺九
```

#### 2.3.5 正反示例

| 类型 | 手牌 | 说明 |
|---|---|---|
| **✅ 正** | 123 万 + 456 万 + 789 万 + 111 条 + 99 条 | 4 副含 1/9，对子 9 条 |
| **❌ 反 → 平胡** | 123 万 + 456 万 + 234 条 + 567 条 + 88 条 | 不含 1/9 |
| **❌ 反 → 清幺九** | 111 万 + 123 万 + 789 万 + 999 万 + 11 万 | 全万字且每副含 1/9 |

### 2.4 一条龙（F05）

#### 2.4.1 判定条件

| 判定项 | ✅ 满足 | ❌ 不满足 |

```
  └─ 是 → ✅ 清一色 ×4
```

#### 5.1.5 正反示例

| 类型 | 手牌 | 说明 |
|---|---|---|
| **✅ 正** | 123 万 + 456 万 + 789 万 + 123 万 + 11 万，缺筒 | 全万字，4 副 + 1 对 → **清一色 ×4** |
