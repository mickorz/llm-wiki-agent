# 功夫川麻（血战川麻）· 开局 UI 交互

> 本章描述开局阶段的玩家可见界面与交互体验，覆盖换三张、定缺及其过渡展示。玩法规则见[基础规则](01-基础规则.md) §四.1，完整时序见[游戏流程](02-游戏流程.md) §五、§六。

## 一、开局衔接

### 1.1 发牌结束后的桌面状态

发牌完成后，牌桌保留四周牌墙、玩家头像、分数和已发手牌。桌面中央依次呈现开局流程：

```
发牌完成 → 换三张（按房间规则） → 定缺（三房） → 正常行牌
```

| 场景 | 桌面表现 |
|---|---|
| 开启换牌 | 桌面中央出现换牌引导，自己的手牌进入选择状态 |
| 不换张 | 不出现换牌选择，直接进入定缺或正常行牌 |
| 三房定缺 | 换牌结束后出现定缺面板 |
| 两房 | 不出现定缺面板，换牌结束后直接开始行牌 |

开局操作期间，桌面重点始终落在自己的手牌与中央操作区；牌河、牌墙和其他玩家的手牌不提供操作入口。其他玩家头像旁以简短状态说明当前进度，例如“选牌中”“已选好”“定缺中”。

### 1.2 公共视觉元素

| 元素 | 表现 |
|---|---|
| 阶段标题 | 桌面中央上方显示“换三张”或“定缺”，使用与正常操作按钮一致的主题色 |
| 倒计时 | 位于阶段标题附近，剩余时间清晰可见 |
| 操作区 | 位于自己手牌上方，不遮挡牌面和已选状态 |
| 其他玩家状态 | 显示在头像附近，不展示其具体选择内容 |
| 提示信息 | 使用桌面中央轻提示或操作区附近说明，避免覆盖手牌 |

## 二、换三张

### 2.1 阶段画面

> 本节 UI 布局以 Draw.io 源文件作为结构化布局输入。

```yaml
layout_id: exchange_cards
layout_source: ./换三张.drawio
layout_format: drawio
layout_role: ui_structure_source
```

解析约定：
- 元素的 `x / y / width / height`、基础空间关系优先读取 `./换三张.drawio`。
- Draw.io 元素 id 必须用 `KW_` 前缀（如 `KW_BTN_ConfirmExchange`），与下游 ui_spec 元素名一一对应。
- 元素业务含义、交互规则、状态变化仍以本章节文字为准。
- 如果 Draw.io 布局与文字需求冲突，以文字需求作为目标行为，并在结构解析结果中记录冲突。

进入换三张时，桌面中央展示阶段标题、倒计时和引导文案（`KW_TXT_ExchangeGuide`）：

> 请选择 3 张同花色手牌进行交换

当房间配置为换四张时，文案中的“3 张”同步替换为“4 张”。标题下方展示本局换牌方向，例如“与对家交换”“与上家交换”或“与下家交换”，让玩家在选牌前明确牌将交给哪一方。

自己的手牌保持完整可见；其他玩家只显示进度状态，不提前展示交换出的牌或换入的牌。

### 2.2 选牌状态

玩家点击手牌可选中或取消选中。选中的牌上移，并以描边或底光强化选中状态；操作区同步显示已选数量，如“已选 2/3”或“已选 3/4”。

| 选牌状态 | 界面反馈 |
|---|---|
| 未选牌 | 保持正常手牌样式 |
| 已选牌 | 上浮并高亮，清楚区别于未选牌 |
| 已选足够张数 | 确认按钮点亮 |
| 少选 | 确认按钮置灰，并提示“还需选择 X 张牌” |
| 多点其他牌 | 当前选择不变，轻提示“请选择 X 张牌” |
| 选到不同花色 | 当前选择不变，轻提示“请选择同花色手牌” |

换牌数量由房间规则决定。玩家需要选择规定数量且同一花色的手牌，才能完成确认。

### 2.3 推荐提示

系统给出的推荐换牌以弱提示呈现，不替代玩家选择。推荐花色的若干手牌可使用柔和底光、角标或“推荐”标记；玩家自行点击其他牌时，推荐效果不妨碍正常选择。推荐内容不在其他玩家视角展示。

### 2.4 确认与等待

选足牌后，玩家可点击“确认换牌”（`KW_BTN_ConfirmExchange`）。确认后，已选牌保持上浮和高亮，操作区改为等待文案：

> 已选好，等待其他玩家

确认期间不再显示可修改的选牌状态。其他玩家完成选择后，其头像附近由“选牌中”切换为“已选好”，但不显示其所选花色和牌面。

### 2.5 换牌方向与结果动画

换牌方向由本局骰子结果确定。4 人局中，3 / 5 / 7 / 9 / 11 点与对家交换，4 / 8 / 12 点与上家交换，2 / 6 / 10 点与下家交换；3 人局的对家方向改为顺时针或逆时针随机；2 人局始终与对家交换。

全桌玩家完成选择后，桌面先短暂停留在等待画面，再播放换牌动画：

| 换牌方向 | 动画表现 | 节奏 |
|---|---|---|
| 与上家 / 下家交换 | 选中的牌沿桌面环形向对应方向移动，换入牌从相反方向进入自己的手牌区 | 轮转约 1 秒 |
| 与对家交换 | 双方牌组沿桌面中线交错移动，形成面对面交换的清晰路径 | 交换约 1 秒；4 人局同时展示约 2 秒 |
| 换入手牌 | 换入牌落入空位并自动整理 | 插入约 0.3 秒，整理约 1.2 秒 |

动画中，换出的牌先离开手牌区，换入牌再落入空位。动画结束后，换三张标题和操作区淡出；玩家能看到完整、重新排序后的手牌。

## 三、定缺

### 3.1 定缺选择面板

> 本节 UI 布局以 Draw.io 源文件作为结构化布局输入。

```yaml
layout_id: select_suit
layout_source: ./定缺.drawio
layout_format: drawio
layout_role: ui_structure_source
```

解析约定：
- 元素的 `x / y / width / height`、基础空间关系优先读取 `./定缺.drawio`。
- Draw.io 元素 id 必须用 `KW_` 前缀（如 `KW_BTN_WanSuit`），与下游 ui_spec 元素名一一对应。
- 元素业务含义、交互规则、状态变化仍以本章节文字为准。
- 如果 Draw.io 布局与文字需求冲突，以文字需求作为目标行为，并在结构解析结果中记录冲突。

三房玩法在换牌结束后进入定缺。桌面中央显示“定缺”标题、倒计时和引导文案（`KW_TXT_DingQueGuide`）：

> 请选择一门花色作为缺门

操作区展示万（`KW_BTN_WanSuit`）、条（`KW_BTN_TiaoSuit`）、筒（`KW_BTN_TongSuit`）三个花色选项。每个选项包含花色图标、花色名称与当前手牌数量，方便玩家直接比较：

| 选项示例 | 信息 |
|---|---|
| 万 | 万字图标 + “万” + 手牌数量 |
| 条 | 条子图标 + “条” + 手牌数量 |
| 筒 | 筒子图标 + “筒” + 手牌数量 |

推荐定缺花色可增加柔和扩散光效或“推荐”标记（`KW_TXT_RecommendTip`）。推荐仅作引导，玩家仍可按规则选择可选花色。

### 3.2 选择与确认

点击花色选项后，选项出现清晰选中态，确认按钮（`KW_BTN_ConfirmDingQue`）同步显示当前选择，例如“确认定缺：条”。未选择花色时，确认按钮保持置灰。

当选择的花色手牌数量达到 7 张及以上时，点击确认后弹出二次确认弹窗：

> 该花色手牌较多，确定要定缺吗？

弹窗提供“取消”和“确定定缺”两个操作。取消后回到花色选择面板，并保留当前选中花色；确定后进入等待状态。选择少于 7 张的花色时，确认后直接进入等待状态。

确认完成后，面板展示：

> 已定缺：条，等待其他玩家

其他玩家头像附近显示“已定缺”状态，待定缺全部完成后再公开各自的缺门花色。

### 3.3 定缺结果展示

全部玩家完成定缺后，桌面依次展示每位玩家的定缺结果：花色图标在头像附近放大回弹，再停留为常驻的缺门标识。展示顺序应让玩家容易确认全桌结果，同时不遮挡手牌和操作区域。

自己的手牌随结果整理：

| 手牌区域 | 表现 |
|---|---|
| 非缺门牌 | 保持原有亮度与正常排序 |
| 缺门牌 | 集中排列在手牌最右侧，显示缺角标并降低亮度 |
| 头像区域 | 常驻展示自己选择的缺门花色 |

定缺展示完成后，中央面板退出，桌面恢复正常摸打布局。

## 四、倒计时与提示

### 4.1 倒计时表现

换三张和定缺共用倒计时样式。常规时间使用主题色；剩余 5 秒时切换为警示色，并播放一次简短提示音。倒计时归零后，操作区从可选状态切换为等待状态，避免玩家误以为仍能继续操作。

### 4.2 自动操作提示

若玩家未在倒计时内完成操作，桌面在结果出现时显示对应轻提示：

| 场景 | 提示 |
|---|---|
| 换三张超时 | 超时自动换牌 |
| 定缺超时 | 超时自动定缺：{花色} |

提示不遮挡换牌动画、定缺标识和后续操作按钮，并在短暂停留后自动消失。

### 4.3 等待与异常提示

网络波动或结果尚未抵达时，保留玩家已完成的选择画面，并显示“等待牌局同步”或“网络异常，请稍候”等轻提示。玩家不需要重复点击确认，也不会看到与当前阶段无关的操作按钮。

当牌局已经进入下一阶段时，旧阶段的面板立即退出，以当前桌面状态为准继续展示。

## 五、重回牌局

玩家中途回到牌局时，直接看到当前正在进行的开局阶段，而不是回到离开前的旧画面。

| 当前牌局状态 | 重回后的画面 |
|---|---|
| 换三张未完成 | 显示换三张面板、当前倒计时和可选择手牌 |
| 换三张已选好 | 显示已选牌与“等待其他玩家”状态 |
| 换牌结果展示中 | 直接呈现当前手牌和即将进入的定缺或行牌画面 |
| 定缺未完成 | 显示定缺面板、当前倒计时和花色选项 |
| 定缺已完成 | 显示等待状态或已公开的缺门标识 |
| 已进入行牌 | 关闭全部开局面板，按正常行牌桌面展示 |

## 六、体验验收

- 玩家在换三张时能一眼看清需换张数、换牌方向、已选数量和同花色限制。
- 换牌推荐可见但不干扰自由选择；确认后全桌等待进度明确，换入牌只在交换动画中出现。
- 玩家在定缺时能直接比较三门手牌数量，理解当前选择、推荐提示和高张数二次确认。
- 定缺完成后，缺门花色在头像和手牌中持续可辨，缺门牌集中于手牌右侧并弱化显示。
- 倒计时告急、超时自动操作、等待同步和回到牌局时，界面始终让玩家明确当前阶段与下一步可做的事。
