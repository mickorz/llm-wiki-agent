# 功夫川麻（血战川麻）· 打牌操作

> 本章按行牌顺序列：摸 → 打 → 碰 → 杠（直杠 / 补杠 / 暗杠）→ 补 → 胡 → 过。每个操作用「时机 / 条件 / 后果」三段表达。
>
> **不可吃牌**为本玩法硬约束（基础规则见 [基础规则](01-基础规则.md) §一.1；胡牌合法性见 [胡牌类型](05-胡牌类型.md)）。

## 一、摸牌

| 维度 | 规则 |
|---|---|
| **时机** | 轮到玩家出牌阶段，从牌墙正序摸 1 张 |
| **来源** | 牌墙中顺时针发牌，每次 1 张 |
| **距离** | 与一般手牌保持 1/4 牌距离 |
| **动画** | 从手牌最右侧从上往下缓冲落下，1 帧效果 |
| **关键约束** | 需在**上一家打出牌的同时**摸牌（与抖小不同） |

**出牌前可响应**：他人打出牌时，本玩家可执行 **碰 / 直杠 / 胡**；操作完成后才轮到本玩家摸牌。

> 出处：2.8.11.1。

## 二、打牌

### 2.1 出牌方式（可配置）

| 方式 | 规则 | 出处 |
|---|---|---|
| **双击出牌**（默认） | 点击已提起的牌可打出 | 2.8.11.1 |
| **单击出牌** | 点击打出不可听牌的牌直接打出，无需提起；勾选时若轮到自己出牌前有牌提起则自动下落 | 2.8.11.1 |
| **滑动出牌**（默认开） | 上滑超过提起高度显示透明状态牌；松开打出；移回则撤回 | 2.8.11.1 |

### 2.2 提牌

| 维度 | 规则 |
|---|---|
| **单击** | 牌面被点击后提起约牌高 1/4 |
| **数量** | 每次只能提起 1 张 |
| **放下** | 点击非牌面空白处可放下；点击该牌牌面**不能**放下 |
| **滑动** | 可滑动选择多张，手牌依次提起（每次提起 1 张），手指离开时手指所在位置对应牌提起 |
| **听牌触发** | 提起「打出可听牌」时弹出听牌提示页面（详见 [番型](04-番型.md) / 听牌标签） |

### 2.3 限制与提示

| 项 | 规则 | 出处 |
|---|---|---|
| **必先打缺牌**（勾选） | 手牌有缺门时打非缺门 → toast「必须先打定缺的那门牌」仅自身可见 1.5s | 可勾选规则 |
| **超时托管** | 超时：若有提起的牌走托管（打新摸的牌）；无提起的牌走托管（打新摸的牌） | 2.8.11.1 |
| **出牌放大**（默认开） | 其他人打牌时放大展示，下一玩家有操作行为后消失 | 2.8.11.1 |

### 2.4 听牌提示标签（向听数 = 1）

> 标签展示规则由服务端实时计算：可胡张数最少按 0 张，倍数最少按 1 倍。

| 标签 | 显示条件 | 优先级 |
|---|---|---|
| **箭头** | 打出成听只有 1 张时 | — |
| **多** | 胡牌张数最多且 ≥ 最少 + 2 | 优 > 大 > 多 > 箭头 |
| **大** | 胡牌倍数最大的牌点（同一牌点多张时最右侧的牌显示） | 同上 |
| **优** | 既符合「大」又符合「多」的牌 | 最高 |

> 出处：2.8.8.2 §听牌标签显示规则。

| 维度 | 规则 | 出处 |
|---|---|---|
| **触发** | 他人打出一张牌，玩家手上有 ≥2 张相同牌时可选碰 | 2.3.1.1 |

| **可碰任何一家** | 是 | 2.3.1.1 |
| **放置位置** | 从左往右根据本局操作顺序放置于手牌**左侧** | 2.8.10.2 |
| **箭头标识** | 碰牌上方显示箭头：↑对家 / ←上家 / →下家 | 2.8.10.2 |
| **过手碰** | 见 §八 | 2.3.1.1 |
| **缺门限制** | 缺门花色**不可碰** | 2.3.5 |
| **碰后** | 碰完轮到自己出牌 | — |

## 四、杠（直杠 / 补杠 / 暗杠）

### 4.1 直杠（明杠 / 刮风）

| 维度 | 规则 |
|---|---|
| **触发** | 他人打出一张牌，玩家手中已有 3 张相同牌 |
| **优先级** | 中（低于胡） |
| **收分** | **2 倍底分** |
| **赔付对象** | **打出该牌的玩家本人** |
| **放置位置** | 手牌左侧，按本局操作顺序 |
| **标识** | 碰牌上方显示箭头：↑对家 / ←上家 / →下家 |
| **缺门限制** | 缺门花色不可直杠 |
| **动画** | 刮风字样 + 中央动画 + 飘分 |
| **后续** | 补牌 1 张（§五）→ 出牌 |

> 出处：2.3.1.2、2.8.10.2。

> ⚠️ **及时雨与补杠时机**：若创房开启「及时雨」（[07-配置 §七.2](07-配置.md)），则摸到补杠牌**必须在当回合补杠**才计补杠分；过手后即使再补杠也不计补杠分（但仍计根数）。此规则与「碰牌当回合不可补杠」（§4.2 关键限制）针对不同场景：前者约束「已过碰牌回合后摸到第 4 张时的补杠窗口」，后者禁止「碰牌的同一回合立即补杠」。

### 4.2 补杠（明杠 / 刮风）

| 维度 | 规则 |
|---|---|
| **触发** | 已碰该牌后，在后续出牌阶段手中有相同的第 4 张 |
| **关键限制** | **碰牌当回合不可补杠**（碰和补杠不能在同一回合执行）；过手后可在后续回合补杠 |
| **收分** | **1 倍底分** |
| **赔付对象** | 所有**未胡**玩家均摊 |
| **标识** | 杠牌上方显示「补」 |
| **缺门限制** | 缺门花色不可补杠 |
| **动画** | 明杠 + 飘分（**先播动画不飘分**；抢杠胡玩家完成选择后再按杠/胡飘分）。响应窗口期间不飘分 |
| **后续** | 补牌 1 张（§五）→ 出牌 |

> 出处：2.3.1.2、2.8.10.2。

### 4.3 暗杠（下雨）

| 维度 | 规则 |
|---|---|
| **触发** | 在非碰牌后的出牌阶段，手中已有 4 张相同牌 |
| **收分** | **2 倍底分** |
| **赔付对象** | 所有**未胡**玩家均摊 |
| **展示** | 3 张牌背 + 1 张牌面（按配置正/反堆叠） |
| **缺门限制** | 缺门花色不可暗杠 |
| **动画** | 下雨字样 + 中央动画 + 飘分 |
| **后续** | 补牌 1 张（§五）→ 出牌 |

> 出处：2.3.1.2、2.8.10.2。

### 4.4 杠的共同后续

| 项 | 规则 |
|---|---|
| **补牌** | 从牌墙正序（或倒序，按配置）抓 1 张 |
| **牌墙增减** | 配置 1：杠后摸牌从**牌墙末**减 1 张；配置 2：从牌墙正序一墩从上到下减 1 张 |
| **缺门限制** | 缺门花色**不可杠**（直杠/补杠/暗杠均不可） |

> 出处：2.3.5、2.8.6 §3。

## 六、胡

> 本玩法**不可吃牌**；9 种独立胡法：自摸 / 点炮 / 抢杠胡 / 杠上花 / 杠上炮 / 海底捞月 / 海底炮 / 天胡 / 地胡；点杠花、一炮多响为创房配置（非胡法，见 [05-胡牌类型](05-胡牌类型.md)）。
>
> 详细条件、限制层（缺门 / 2 倍起胡 / 后四张必胡）、过手胡、计分见 [胡牌类型](05-胡牌类型.md) 与 [结算](06-结算.md)。

### 6.1 操作按钮显示

| 场景 | 按钮 |
|---|---|
| **可自摸** | 【自摸】+【过】，左侧显示本次胡的牌 + 倍数（自摸按自摸显示） |
| **可点炮 / 抢杠胡** | 【胡】+【过】，按钮上方显示本次胡的牌 + 倍数（非自摸不含自摸） |
| **倍数为封顶** | 显示「封顶」，且倍数仅显示封顶倍数 |
| **后四张必胡**（勾选且满足） | 不显示【过】 |
| **配置开启托管** | 超时默认胡 |

### 6.2 摆放与动画

| 项 | 规则 |
|---|---|
| **摆放** | 摊开摆放在自己手牌右侧间隔 1/4 牌距离，显示手掌标记 |
| **自摸动画** | 光柱动效 - 番型动画（对应方位玩家手牌前播放）+ 飘分（正分黄、负分灰） |
| **点炮 / 抢杠胡动画** | 点炮动画 - 光柱动画 - 番型动画 + 飘分 |
| **一炮多响动画** | 一炮多响动画 - 光柱动画 - 番型动画 + 飘分 |
| **呼叫转移动画** | 点炮 - 光柱 - 杠上炮 + 飘分 + 呼叫转移飘分 |

> 出处：2.8.10.2 §胡牌。

## 八、过手规则

| 项 | 触发 | 结果 | 出处 |
|---|---|---|---|
| **过手碰**（创房默认开启）| 可碰未碰 | 摸/杠牌之前不可再碰同一张可碰牌 | 2.3.1.1 |
| **过手胡**（创房默认开启）| 可胡未胡（自摸 / 捉炮） | 摸牌/碰/杠前不可再胡（**包含所有可胡牌**，不仅限未胡的那张） | 可勾选规则 |
| **过手加番可胡**（创房默认开启）| 勾选后，可胡不胡后未过手时，有人打出番数更高的牌，可无视过手胡继续胡；必须比同一圈内前面最高倍数**更高** | 例：A 可胡 1万（2番）/4万（1番）/7万（2番）→ A 过 B 打 1万 → C 打 4万（不可胡，番数更低）；C 打 7万（不可胡，番数与 1万相同，没有更高） | 可勾选规则 |

**依赖关系**：**过手胡未勾选**时，**过手加番可胡**变灰不可勾选。

**提示**：
- 触发「漏碰不碰」浮动提示：「当前未过手，无法碰牌」1.3s
- 触发「漏胡不胡」浮动提示：「当前未过手，无法胡牌」1.3s

> 出处：可勾选规则、2.8.12。

## 十、特殊出牌规则

### 10.1 出牌 → 摸牌的连贯性

```
A 出牌 → B 摸牌（与 A 出牌同时开始，不等 A 出牌动画结束）
```

> 出处：2.8.11.1 §摸牌。

### 10.2 一炮多响（v1 不开放可配置，默认关闭）

| 配置 | 行为 |
|---|---|
| **不可一炮多响**（默认，v1 唯一模式） | 逆时针顺序优先级胡牌（吃胡 / 抢杠胡） |
| **允许一炮多响**（v1 未实现，预留） | 多人可同时胡一家 |

> 出处：2.3.1.4、2.3.1.5。

### 10.3 后四张必胡（创房可勾选 · 默认未勾选）

| 项 | 规则 |
|---|---|
| **触发** | 剩余最后 4 张时 |
| **规则** | 无论自摸还是点炮必须胡牌 |
| **UI** | 出现【胡】按钮后浮动提示「【后四张必胡】」玩家胡牌后才消失 |

> 出处：可勾选规则、2.8.12。

### 10.4 2 倍起胡（创房可勾选 · 默认未勾选）

| 项 | 规则 |
|---|---|
| **触发** | 胡牌番数 < 2 时 |
| **规则** | 不可胡（但仍可听牌，不会被查叫） |
| **UI** | 听牌按钮显示「2 倍起胡 番数不足」 |

> 出处：可勾选规则、2.12.1.2。

## 十一、操作速查表

| 操作 | 时机 | 条件 | 主要后果 |
|---|---|---|---|
| 摸 | 轮到出牌阶段 | — | 手牌 +1，可提牌 |
| 打 | 提牌后 | 不违反缺门（勾选时） | 出牌 + 进入响应窗 |
| 碰 | 他人出牌后响应 | 手牌 ≥2 张同花色同数 | 副露 +1 组；轮到自己出牌 |
| 直杠 | 他人出牌后响应 | 手牌有 3 张同花色同数 | 副露 +1 组；收 2 倍底分（打牌者付）；补牌 +1 |
| 补杠 | 自己的出牌阶段 | 已有碰 + 手中有第 4 张 | 副露变杠；收 1 倍底分（所有未胡均摊）；补牌 +1 |
| 暗杠 | 自己的出牌阶段 | 手中 4 张同花色同数 | 副露变杠（3 背 1 面）；收 2 倍底分（所有未胡均摊）；补牌 +1 |
| 补牌 | 杠后 | — | 手牌 +1 |
| 胡 | 自摸 / 响应 | 牌型合法 + 缺门满足 + 满足其他限制 | 退出本局；进入结算 |
| 过 | 响应时 | — | 放弃此次响应；过手胡/碰规则生效 |
